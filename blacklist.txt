# Blacklist: nothing listed here may be present in the final image.
# One entry per line; shell-style globs allowed (plasma-nm-*). The build:
#   1. [remove]       : removes these packages from the base image with dnf, before
#                       installing whitelist.txt (dependencies are respected);
#   2. installs whitelist.txt;
#   3. fails if any entry of [remove] or [repos] is still present.
# Never force a removal (rpm --nodeps): unwanted services pulled by mandatory
# dependencies (geoclue2, avahi) are masked in build/configure.sh (Kyanite ADR 0002).
# All steps run in a single image layer: the final image keeps no trace of what was
# installed and then removed.
