# 0038 — Move to Fedora 45 now, through the drift pull request

Date: 2026-11-05. Status: accepted (maintainer: "Option 2", rather than pinning `fedora-bootc:44`).

## Context
`quay.io/fedora/fedora-bootc:latest` moved to 45 (`45.20261104.0`, created 2026-11-04 11:06 UTC,
checked with `skopeo`). Since then every CI build fails the boot test on one line: `authselect check`
prints "Current authselect configuration is valid." instead of "Current configuration is valid."
(issue #40, PR #39 build). The manifest check reports drift (rc 10), as ADR 0014 expects.

## Decision
- The boot test accepts both `authselect check` messages. Nothing else in the image changes here.
- Then the path of ADR 0014: the next build on `main` publishes `:testing` and opens the drift pull
  request (F45 manifest). The maintainer merges it after the VM checks it lists; Claude does not.
- The Discover test of the LUKS keymap karg (ADR 0037) uses that update: the VM installed from
  the F44 ISO gets the F45 deployment.

## Not seen yet
The F45 image booted in a VM, the drift pull request, the ISO rebuilt on F45 (`swarf-os-45-x86_64.iso`).
